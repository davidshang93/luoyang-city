Vehicle models in assets/models/cars/ (sedan, suv, taxi, police, sports, van, bus):
- derived from the CARLA Simulator vehicle set — "CARLA Simulator (carla.org)", licensed CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/); glTF conversion by Valdrada (M. K. Turkcan), taken from the
  Hugging Face dataset mehmetkeremturkcan/valdrada, Content/models/fleet24/.
- truck.glb: original model by M. K. Turkcan (Valdrada, "boxtruck26"), CC BY 4.0.
- Changes made for this project (tools/models/build-cars.mjs): one level of detail kept, wheels split into separate
  parts, textures resized and re-encoded, every manufacturer badge, model name, tyre / plate / livery lettering removed,
  number plates, taxi / police / bus / truck markings and lamp glow replaced with this project's own.
  Imagery showing these vehicles should carry "CARLA Simulator (carla.org), CC BY 4.0".
